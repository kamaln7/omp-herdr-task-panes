# omp-herdr-task-panes

An [omp](https://github.com/can1357/oh-my-pi) extension that shows every subagent run as a live [herdr](https://herdr.dev) split pane. Your pane stays on the left; agents tile the right and close when they finish.

<div align="center">

https://github.com/user-attachments/assets/15ff9e90-ff27-45b5-b6d8-3e530993d784

</div>

```sh
git clone https://github.com/kamaln7/omp-herdr-task-panes ~/.omp/agent/extensions/herdr-task-panes
```

Run omp inside a herdr pane. Requires `bun`. Disable with `OMP_HERDR_TASK_PANES=0`.
